# Discounts, Flash Sales & Promo Codes — Customer Guide

Guide for shoppers using the Tab3een online store (and what they see at the counter).

---

## 1. Automatic product discounts

Some products show a **lower price** during a campaign:

- You may see a **new price** and a crossed-out **old price**.  
- The discount is applied automatically in the cart and at checkout.  
- No code is needed for these offers.

Discounts may depend on:

- The product or category  
- The campaign dates  
- Your customer group (if the store assigned you to one)  
- Stock / flash sale limits  

---

## 2. Flash sales

On the store home page, the **Flash deals** section shows time-limited offers:

- Current sale price  
- Previous price (when available)  
- How much of the offer is left (sold % / quantity left)  

Tap **Add to cart** on a flash deal to buy at the campaign price while it lasts and while stock/quota remains.

---

## 3. Promo codes (coupons)

### On the online store

1. Add products to your cart.  
2. Go to **Checkout**.  
3. In the order summary, enter your **promo code**.  
4. Press **Apply**.  
5. If valid, you will see a confirmation and updated total.  
6. Place the order — the code is checked again when the order is created.

### At the physical store (POS)

Give your code to the cashier. They enter it in the discount screen before completing payment.

---

## 4. Why a promo code might not work

| Message / situation | What it means |
|---------------------|----------------|
| Invalid code | Typo, or code does not exist |
| Expired | Outside the valid dates |
| Usage limit reached | Code used too many times (overall or by you) |
| Minimum cart | Spend more to unlock the code |
| First order only | Code is for new customers only |
| No eligible products | Code applies only to certain products/categories not in your cart |
| Login required | Sign in to use this code |
| Wrong customer group | Offer is for a specific customer group |

Codes are **not case-sensitive** (`save10` = `SAVE10`).

Usually **only one promo code** can be used per order.

---

## 5. How savings appear

- **Product offers / flash:** lower price on the item line.  
- **Cart-wide code:** discount on the whole order total.  
- **Product-scoped code:** discount only on matching items; other items stay at normal (or automatic promo) price.

Delivery fees (if any) are calculated separately unless the store tells you otherwise.

---

## 6. Returns

If you return an order that used a promo code, the store may **restore** your right to use that code again (depending on store settings). Flash sale quantities may also be adjusted.

---

## 7. Tips

- Check Flash deals for limited-time prices.  
- Apply your promo code **before** confirming the order.  
- If a code fails, read the message and adjust the cart or ask support.  
- Keep codes private if they are single-use or personal.
